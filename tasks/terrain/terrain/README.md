# Террейн

## Что реализовано
* Генерация ландшафта с помощью многооктавного шума Перлина (fBm) на CPU.
* Отрисовка сетки 512x512 с смещением вершин по высоте.
* Диффузное освещение с расчетом нормалей через производные (dFdx/dFdy).
* Свободная камера для перемещения над ландшафтом (WASD + мышь).

## Что не реализовано и почему
* **Текстура высот 4096x4096 на GPU:** Фреймворк Etna не предоставляет удобного API для загрузки текстур (`uploadImage` отсутствует). Попытка ручной загрузки через `vk::CommandPool` и `vkCmdCopyBufferToImage` приводит к крашу приложения на интегрированной графике Intel Iris Xe (драйвер Mesa/ANV на Linux). 
* **Тесселяция:** В `etna::GraphicsPipeline::CreateInfo` отсутствует поле `tessellationState`. Фреймворк не поддерживает создание пайплайнов с тесселяционными шейдерами.
